# 📈 Fintech Stock Analytics Dashboard

An interactive, real-time financial web application that bridges Computer Science foundations with financial market analysis. This application fetches live market data using the Yahoo Finance API and calculates dynamic trend indicators.

## 🚀 Live Demo
*Optional: If you deployed it on Streamlit Community Cloud, paste your link here!*

## ✨ Features
* **Live Data Fetching:** Downloads real-time market data directly from Yahoo Finance.
* **Interactive Charting:** Displays interactive price movement trends and Simple Moving Averages (SMA) using Plotly.
* **Key Metrics:** Instantly calculates and displays current price points and percentage changes.
* **Dynamic Sidebar Controls:** Allows users to input any global stock ticker (e.g., AAPL, MSFT) and adjust the moving average windows on the fly.

## 🛠️ Tech Stack
* **Language:** Python
* **Web UI Framework:** Streamlit
* **Libraries:** Pandas, Plotly, yfinance
